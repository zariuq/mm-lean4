# Documentation Archive

This directory contains historical documentation from the mm-lean4 verification project development (November-December 2025).

## Purpose

These documents are archived for historical reference but are **not current**. For current project status, see the files in the project root:

- **CURRENT_STATUS.md** - Current build status, what's proven, what needs work
- **COMPLETION_ROADMAP.md** - Strategic overview and completion path
- **WEEKS_STUCK_ROOT_CAUSE.md** - Analysis of dead code cleanup (Dec 2025)
- **DEAD_CODE_CATALOG.md** - Documented eliminated code
- **CLAUDE.md** - Project instructions and architecture
- **how-to-lean-batteries.md** - Lean proof tactics and patterns

## Directory Structure

### session_summaries/
Session progress reports and summaries from various development sessions.

### phase_completions/
Documentation of completed phases and milestones during development.

### analysis/
Deep-dive analysis documents exploring design decisions and alternatives.

### historical/
Other historical documents including proof attempts and status snapshots.
